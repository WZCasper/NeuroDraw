# NeuroDraw

Веб-сервис для стримеров: проведение розыгрышей и подведение итогов конкурсов среди зрителей YouTube, Twitch, TikTok и Instagram.

Полностью готовый к запуску сайт — 3 файла, без сборщиков, без Node.js, без каких-либо установок.

---

## Как загрузить сайт в репозиторий GitHub (WZCasper/NeuroDraw)

Это можно сделать прямо в браузере, без установки программ и без знания команд.

1. Откройте страницу репозитория: https://github.com/WZCasper/NeuroDraw
2. Нажмите **"uploading an existing file"** (ссылка на пустой странице репозитория) — либо кнопку **"Add file" → "Upload files"**, если репозиторий уже не пустой.
3. Перетащите в появившееся окно все три файла из этой папки:
   - `index.html`
   - `style.css`
   - `script.js`
4. Внизу страницы в поле сообщения коммита впишите что-то вроде `Первая версия сайта` и нажмите зелёную кнопку **"Commit changes"**.
5. Готово — файлы в репозитории.

### Как включить бесплатный хостинг (GitHub Pages), чтобы сайт открывался по ссылке

1. В репозитории откройте вкладку **Settings** (вверху).
2. В левом меню выберите **Pages**.
3. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
4. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт станет доступен по адресу вида:
   `https://wzcasper.github.io/NeuroDraw/`

Обновлять сайт в будущем так же просто: открываете нужный файл в репозитории на GitHub, нажимаете иконку карандаша (редактировать), вносите правки и сохраняете — изменения появятся на сайте автоматически в течение минуты.

## Что уже полностью работает

- Переключение платформ: YouTube, Twitch, TikTok, Instagram
- Ввод участников списком (по одному нику на строку)
- Фильтр «Исключать дубликаты участников»

- Адаптивная вёрстка под мобильные экраны

## Скрытность окна «Заданный победитель» от трансляции OBS

Окно администратора теперь **автоматически не показывается**, если сайт открыт внутри OBS как источник **«Браузер» (Browser Source)** — именно так его и нужно добавлять в сцену, если вы ведёте розыгрыш прямо на сайте во время эфира.

Как подключить правильно:
1. В OBS: **Источники → + → Браузер (Browser Source)**.
2. В поле URL вставьте адрес вашего сайта (например, `https://wzcasper.github.io/NeuroDraw/`).
3. Готово — на этом источнике комбинация `Shift + F8` и скрытая точка в углу табло работать не будут: сайт сам определяет, что его рендерит OBS, и не даёт окну открыться.

Важное техническое уточнение, без которого было бы нечестно промолчать: если вместо «Браузер» вы захватываете в OBS **окно самого браузера целиком** («Захват окна» / Window Capture) — такая защита технически невозможна в принципе, ни на одном сайте в мире. В этом случае OBS записывает буквально те же самые пиксели, что видите на экране вы сами, поэтому если окно открыто у вас на экране — оно попадёт и в трансляцию. Это не недоработка именно этого сайта, а особенность того, как работает захват экрана. Чтобы окно администратора гарантированно не попало в кадр, используйте именно вариант «Браузер (Browser Source)» из пункта 1–2 выше.

## Что требует отдельной доработки (честно, без имитации)

Вкладка **«По ссылке»** (автосбор комментариев/подписчиков по ссылке на видео или стрим) в текущей версии показывает понятное пояснение для пользователя, но не скачивает реальные данные с YouTube/Twitch/TikTok/Instagram.

Это сделано осознанно: такой автосбор требует:
- регистрации приложения в официальном API каждой платформы (YouTube Data API, Twitch API и т.д.);
- получения API-ключей/токенов;
- серверной части (бэкенда), которая будет обращаться к этим API, потому что сами платформы не разрешают делать такие запросы напрямую из браузера зрителя по соображениям безопасности.

Сделать вид, что кнопка «считывает» реальных подписчиков без всего перечисленного, означало бы показывать фейковые данные — этого в проекте нет. Если понадобится добавить реальный автосбор — это отдельная задача по разработке бэкенда с ключами API конкретных платформ, и я могу помочь с ней отдельно.
