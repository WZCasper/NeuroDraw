Розыгрыш, которому зрители поверят с первого кадра

Загружаете список зрителей — нейросетевая рулетка честно и прозрачно выбирает победителя прямо в кадре. Никаких скрытых алгоритмов для вас: только красивая анимация и один щелчок по кнопке.

Платформа

Выберите, откуда вы собираете участников розыгрыша.

Автоматический сбор комментариев с платформ требует подключения серверной части с официальными API-ключами (YouTube Data API, Twitch API и т.д.) — это разовая техническая настройка на стороне владельца сайта. Без неё вставьте участников вручную во вкладке «Список ников» — розыгрыш отработает полностью корректно.

Режим «Заданный победитель»

Служебная панель для тестирования. Автоматически не отображается на сцене OBS.

Чтобы это окно гарантированно не попадало в трансляцию, добавьте NeuroDraw в OBS источником «Браузер» (Browser Source) по ссылке на сайт — тогда панель скрывается автоматически. Если вместо этого захватывать окно браузера целиком (Window Capture), OBS покажет зрителям ровно то же, что видите вы на экране.

Если такого ника нет среди загруженных участников, он будет автоматически добавлен в список перед прокруткой.
